# Membuat Object Kartu

Object kartu yang akan digunakan hanya 1 saja, namun dalam 1 object kartu itu terdapat 5 monster/warna kartu yang berbeda, dimana dalam gameplay permainan yang akan dibuat nanti adalah mencocokkan monster/warna kartu yang ada pada setiap kartu. Sebelumnya, silahkan unduh terlebih dahulu gambar-gambar kartu yang sudah disediakan.

## [Download](https://gifdicoding.blob.core.windows.net/academygametizen3/AssetCardMatch.zip)

![01](/assets/002/01.png)

1. Buat project baru terlebih dahulu. Klik **File** > **New** > **New Empty HD Landscape 720p project** > **Open**.

   ![02](/assets/002/02.png)

   Dalam tutorial ini akan menggunakan ukuran HD karena sudah menggunakan resolusi berukuran 1280x720.

2. Tambahkan object Kartu, Klik kanan pada layout > **Pilih Insert new object** > Pilih **Sprite** > Beri nama **Kartu**. Lalu import ke-enam gambar itu dengan Klik kanan pada **Animation frames** > **Import frames** > **From files** > **select semua kartu**.

   ![03](/assets/002/03.png)

3. Atur setting parameter **"Animation Speed"** pada Animation **Default** menjadi **0**.

   ![04](/assets/002/04.png)

   Langkah ini bertujuan, ketika game dijalankan maka kartu tidak secara otomatis terbuka.

4. Kemudian susun Kartu dengan cara salin (CTRL + C) pada kartu dan paste (CTRL + V) di posisi yang berbeda.

   ![05](/assets/002/05.gif)

5. Kemudian susunlah seperti dibawah ini:

   ![06](/assets/002/06.png)

   Anda bisa copy object secara cepat dengan menekan tombol CTRL saat dragging object, agar object tertata rapi, tekan juga tombol SHIFT saat dragging object.
